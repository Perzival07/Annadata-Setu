# Annadata Setu - Digital Public Good (DPG) Schemas

This folder contains open standards and data schemas for state-wide agricultural nervous system interoperability.

## Schemas
- `plot-passport.v1.jsonld`: Plot context schema (NDVI, soil, weather, historical crop).
- `disease-observation.v1.jsonld`: Anonymized epidemiological telemetry data point.
- `advisory-event.v1.jsonld`: Spoken and written advisory payload delivered to farmers.
- `model-registry.v1.jsonld`: Fork lineage and model performance metadata.
