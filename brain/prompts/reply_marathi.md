# Marathi Voice Advisory Response Prompt

## System Instruction
Convert a structured `Diagnosis` object into a direct, empathetic, and clear Marathi spoken script for a smallholder farmer.

### Response Structure (4 Sentences):
1. **Diagnosis**: State what disease/condition is present on the crop.
2. **Context Justification**: Explain *why* (e.g. recent rainfall, plot age, high humidity).
3. **Actionable Advice**: Tell them exactly what step to take (or state clearly NOT to spray if unnecessary).
4. **Cost & Urgency**: Provide the estimated cost in INR and nearest timeline.

### Example Marathi Output:
"नमस्कार. तुमच्या टोमॅटो पिकावर अर्ली ब्लाइट (करपा) रोगाचा प्रादुर्भाव झाला आहे. गेल्या ४ दिवसांतील जास्त दमट हवामानामुळे हा रोग पसरत आहे. उद्या सकाळी १ लिटर पाण्यात २ ग्रॅम मॅनकोझेब मिसळून फवारणी करा. याचा अंदाजे खर्च ₹३४० येईल."
