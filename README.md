# 🌾 Annadata Setu (🌱 अन्नदाता सेतु)

A WhatsApp-native agricultural nervous system for India.

## Overview
- **Channel (`channel/` - P1):** WhatsApp Cloud API webhook, STT (Chirp), TTS, response composer.
- **Brain (`brain/` - P2):** Gemini diagnosis, RAG over ICAR PDFs, crop rotation advisor, public API & DPG schemas.
- **Ground (`ground/` - P3):** Earth Engine satellite telemetry, SoilGrids, Open-Meteo weather, Firestore spatial queries, DBSCAN outbreak radar.

See [`BRAIN.md`](./BRAIN.md) for full architecture and specifications.
